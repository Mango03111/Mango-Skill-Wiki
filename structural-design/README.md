# Structural Design

本分类用于存放与机械结构设计、CAD/SolidWorks 建模、装配体分析、尺寸冲突检查、运动仿真说明书生成等相关的 Skills。

## Skills

| Skill | 说明 | 可上传压缩包 |
|---|---|---|
| [`mechanical-modeling-doc`](./mechanical-modeling-doc/) | 根据说明书、CAD、图片和文档资料生成完整建模说明书 | [`mechanical-modeling-doc.skill.zip`](./#skillPackage/mechanical-modeling-doc.skill.zip) |

## 使用方式

1. 进入 [`#skillPackage`](./%23skillPackage/) 文件夹；
2. 下载对应的 `.skill.zip` 压缩包；
3. 在支持 Skills 的 ChatGPT 环境中上传并安装；
4. 上传机械设计说明书、CAD、图片、图纸等资料；
5. 使用类似下面的提示词调用：

```text
使用 mechanical-modeling-doc 技能，帮我把这些资料整理成完整 SolidWorks 建模说明书。
```
