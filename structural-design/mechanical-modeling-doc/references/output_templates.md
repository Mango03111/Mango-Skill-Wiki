# Output Templates

Use these templates for consistent output.

## 1. Modeling Overview

```markdown
# [项目名称] 建模概述

## 1. 设计对象
- 设备/机构名称：
- 类型/型号：
- 用途：
- 输入资料：

## 2. 建模目标
- 建模软件：solidworks / cad / other
- 模型精度：概念模型 / 简化运动装配体 / 工程展示模型 / 制造级模型
- 必须体现的功能：

## 3. 主要技术参数
| 项目 | 数值 | 来源 |
|---|---:|---|

## 4. 核心运动链
> 动力源 → 传动件 → 主运动件 → 执行机构 → 工作输出

## 5. 建模边界
| 内容 | 处理方式 | 说明 |
|---|---|---|
```
